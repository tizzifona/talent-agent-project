Blue Hope talent database

Clean the list. Then work with it.

This app takes overlapping talent files, builds one person per contact, and keeps that table ready for review, export, or outreach. The assistant on the right stays with you on every step.

01 · Import Deduplicate overlapping files Upload CSV or Excel sources. Matching uses email, then phone, then a cautious name check. Uncertain rows go to review instead of being guessed.
02 · Tables Keep a working table Each successful run is saved. You can preview people, rename the table, export CSV or Excel, or remove it from the library.
03 · Outreach Prepare mailing later When a table is ready, mailing settings let you choose who would be contacted. Sending still belongs to the re-engagement step; this page only prepares the segment.
